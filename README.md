# JanConnect

JanConnect is a Smart Grievance Portal for citizens to raise complaints and for administrators to manage and resolve them.

## Tech Stack

- Backend: Node.js, Express, MongoDB, Mongoose
- Frontend: React, Vite, Tailwind CSS

## Structure

- `docs/` - project documentation and submission assets
- `server/` - backend API and database logic
- `client/` - frontend application

## Setup

1. Install dependencies inside `server/` and `client/`.
2. Configure the `.env` files.
3. Start the backend and frontend development servers.
